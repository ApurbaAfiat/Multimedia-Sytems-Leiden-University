Problem 1 Assessment:

I implemented a parser in C for the MovieLens 10M dataset that loads movies.dat
and tags.dat into RAM. The parser reads all movies into a dynamically growing
array of Movie structs, then attaches tags to each movie using binary search on
the sorted movie array.

The moviesearch program supports:
  --title [keywords]   all keywords must appear in the movie title (AND)
  --year [year]        movie must match this year
  --genre [genres]     all genres must appear in the movie's genre list (AND)
  --tag [tags]         all tags must match (substring, case-insensitive) (AND)

Search is case-insensitive throughout. Title and tag matching use substring
search; genre matching is exact (case-insensitive).
